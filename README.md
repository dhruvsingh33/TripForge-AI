## 🚀 Overview

AI Trip Planner is a modern travel planning application where users can:
- Sign in using Google
- Create trips by selecting destination, days, and preferences
- Get AI-generated itineraries
- View places and hotel recommendations
- Save and manage trips securely

This project is designed for **learning, demos, and resume showcase**.

---

## 🧑‍💻 Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend & Services
- Google Gemini API (AI itinerary generation)
- Google Places API (places & hotels data)
- Firebase Authentication (Google OAuth)
- Firebase Firestore (trip data storage)

---

## ✨ Features

- Google Sign-In using Firebase Authentication  
- AI-generated travel itineraries (day-wise plan)  
- Place and hotel suggestions using Google Places API  
- Save trips securely in Firestore  
- Clean and responsive UI (mobile-friendly)
